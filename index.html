Immerse yourself
in the comic.

Komga and Kavita are great file browsers, but reading comics on a phone still means pinching and panning across tiny text. Comics Now! is a self-hosted CBZ/CBR/PDF server that uses local AI to detect panels and speech bubbles automatically—paired with a browser-based visual editor when you want to tweak the reading order yourself.

Public-domain and open-licensed pages, loaded locally. No account and no upload. The GVE editor is designed for a desktop browser.

Start it in one command.

Docker Compose, Docker CLI or npx. Node and SQLite underneath, with no JVM and no paid tier.

GitHub npm Docker Hub 

services:
  comics-now:
    image: ghcr.io/comicsnow/comics-now:latest
    container_name: comics-now
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/data
      - /path/to/your/comics:/comics:ro
    restart: unless-stopped

Built for huge libraries and small screens.

The parts that matter after you have scanned ten thousand pages. No dashboards, no busywork.

  • Panel and bubble zoom

    Local ONNX models find the boxes on every page. Tap one and it fills the screen, in right-to-left manga or western comics.

  • Crossover reading maps

    See how a tie-in connects across series and publishers, and which issue to open next.

  • Metadata that fills itself in

    ComicVine, Metron and the Grand Comics Database, with Gemini cover matching when the filenames are wrong.

  • An MCP server for your shelf

    Sixty-plus tools let Claude, Gemini CLI or Cursor search the library, fix tags and build reading lists.

  • CBR and PDF, handled

    Convert to streamable CBZ once. Keep or delete the originals, with separate rules for CBR and PDF.

  • Offline and E-Ink

    Resumable downloads for tablets, plus monochrome and color display modes for Boox, Kobo and PocketBook.

Why not just use Komga or Kavita?

They are better if you need OPDS clients, EPUB novels and a large ecosystem of third-party apps. Comics Now! is built for reading comics on a phone: local AI finds panels and speech bubbles, a visual editor fixes the misses, and a reading map shows how crossover issues connect. You can run all three and pick the reader you prefer.

Do I need a GPU for panel detection?

No. The detectors run locally on your CPU or GPU, and pages can also go to Modal serverless GPUs so a large import does not slow down your home server.

How does CBR and PDF conversion work?

Comics Now! converts RAR/CBR and PDF files into streamable CBZ archives with page integrity checks. You can keep or delete the originals, with separate rules for each format.

Is it really free?

Yes. The server and the editor are AGPL-3.0, with no account and no paid tier. You bring the hardware, the comics and, if you want cloud tagging or detection, your own API keys.
